# 54 News HD — two-repository GitHub package

This package contains two separate projects:

- `54-news-hd-website/` — public channel website
- `54-news-hd-admin/` — independent admin panel

Read `54-news-hd-admin/README.md` for complete setup instructions.

The website embeds playlist:
https://youtube.com/playlist?list=PLBIM0Ccowqhg

Important: the admin panel requires a fine-grained GitHub token with access only to the website repository and Contents read/write permission. Enter the token at runtime; never hardcode or commit it.
